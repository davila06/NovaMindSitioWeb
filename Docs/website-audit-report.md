# Auditoría del portal web NALA / PawTrack CR

**Fecha de revisión:** 2026-09-29  
**Alcance:** código fuente y configuración disponibles en este workspace (`c:\Sitio WEB`).  
**Criterio de evidencia:** cada hallazgo remite a archivos del repositorio. “No localizado” significa que no hay evidencia de implementación en este workspace; no prueba que una aplicación externa no exista. No se inspeccionó ningún despliegue, base de datos, cuenta de analytics ni repositorio remoto.

> **Identidad y alcance comprobados.** `Docs/NALA.md` define NALA como nombre interno evolucionado a PawTrack CR. El código implementa el sitio corporativo Novamind Global y una página de producto `/productos/pawtrack` llamada “Mi Mascotica”. Las rutas API locales son contacto, newsletter, health y recepción de telemetría; no se encontró una app de mascotas con autenticación, persistencia o endpoints de dominio. Por tanto, este documento audita el portal presente y compara la landing con la visión documentada; no certifica el MVP descrito en esa visión. Evidencia: `Docs/NALA.md`, `package.json`, `app/productos/pawtrack/page.tsx`, `app/api/contact/route.ts`, `app/api/newsletter/route.ts`, `app/api/health/route.ts`, `app/api/monitoring/error/route.ts`.

### Hallazgos de descubribilidad

- `app/sitemap.ts` incluye home, about, contacto, blog, industrias, roles, privacidad, todos los productos y entradas de blog/industria/rol. No incluye `/servicios`, `/casos`, `/comparar`, `/demos` ni `/terminos`. Eso prueba una omisión del sitemap, no que cada página sea huérfana.
- `/gracias` y `/offline` se excluyen de robots/sitemap; `/gracias` lleva `noindex`, coherente con páginas utilitarias.
- El footer y el header no exponen el mismo conjunto de rutas/productos. El footer prioriza siete productos y no incluye enlaces visibles a privacidad/términos en el fragmento de navegación disponible.
- No se ejecutó un crawler HTTP del dominio ni se validaron todos los href contra respuestas desplegadas; no se declara ningún enlace roto confirmado.

Evidencia: `app/sitemap.ts`, `app/robots.ts`, `app/gracias/page.tsx`, `components/layout/Navbar.tsx`, `components/layout/Footer.tsx`, `data/site.ts`.

## 6. Mobile First

- **Responsive:** hay clases Tailwind para `sm`, `md`, `lg` y diseños en grid que cambian por tamaño; el header desktop se oculta bajo `md`, hay menú móvil y navegación inferior fija. Evidencia: `components/layout/Navbar.tsx`, `components/layout/BottomNav.tsx`, `app/contacto/page.tsx`, `tailwind.config.ts`.
